# 可安装的看板应用示例

先在 DSH 安装 Core 0.2.1 连接层并配对，然后在此目录执行 `pnpm pack --pack-destination ../../.runtime/packages`。在 DSH 插件管理中安装生成的示例包并启用，即会在看板「开发与协作」中看到「插件应用示例」。点击应用进入详情后可打开其独立页面；停用或卸载会注销入口。

示例只使用公开的 `ctx.dshCore.registerApplication`。应用自己提供本机页面；Core 持有目录、连接状态和任务/资源契约。正式应用在自己的仓库管理业务源码、接口、鉴权和状态。页面入口不携带 Core 凭据，也不能访问 Core 的私有存储。
